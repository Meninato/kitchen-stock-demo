- After docker-composer up command, open a new terminal and run the command below, it will generate 5 keys copy and save them 
along with the root token.
- Everytime you start the docker compose you don't need to repeat the process, just use the keys you noted to unseal.

docker exec -it kitchen-vault vault operator init
